# Product Vision

## Purpose
This file captures the product intent, user value, and long-term vision for `web-pdf`.

## How To Use
- Update when target users, positioning, or success criteria evolve.
- Keep focus on product outcomes, not low-level implementation.
- Use this to align roadmap and feature choices.

## Template

### Vision Statement
Make building PDFs feel like building UI: fast, intuitive, predictable, debuggable, and type-safe.

### Target Users
- Frontend and full-stack developers generating PDFs
- SaaS teams producing invoices, reports, exports, and documents
- Product teams that need fast preview loops without sacrificing PDF fidelity

### Core Value Proposition
- Familiar component authoring patterns
- Browser preview for rapid iteration
- Strict supported utilities with autocomplete and validation
- Advanced document features on top of React-PDF

### North Star
Become the standard developer layer on top of `@react-pdf/renderer`.
