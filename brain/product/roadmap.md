# Product Roadmap

## Purpose
This file tracks major planned product phases, themes, and future expansion ideas.

## How To Use
- Update as priorities move.
- Keep roadmap themes outcome-based rather than task-sized.
- Use `brain/tasks/roadmap.md` for more operational planning.

### Long Term

- Visual builder or editor
- Template marketplace
- Table engine and chart components
- CLI scaffolding and linting support
