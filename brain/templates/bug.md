# Bug Template

## Purpose
This file provides the standard structure for documenting bugs and their lessons in `brain/bugs/`.

## How To Use
- Copy this template when a bug is discovered or fixed.
- Focus on root cause and prevention, not only symptoms.
- Keep entries factual and reproducible.
